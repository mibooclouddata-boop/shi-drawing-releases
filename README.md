# SHI 도면 프로그램

작업지시서와 도면을 번호별 PDF로 정리하는 Windows 프로그램입니다.

[최신 설치파일 다운로드](https://github.com/mibooclouddata-boop/shi-drawing-releases/releases/latest/download/SHI_Drawing_Setup.exe)

## 설치와 인증

설치 시 한국어·영어·중국어·베트남어 중 언어를 선택하고 회사명, 부서, 이름, 발급받은 인증키를 입력합니다.
인증키는 처음 등록한 PC 한 대에 연결되며, 사용기간 안에서 사용할 수 있습니다.

## 업데이트

프로그램의 설정 → 업데이트 확인에서 새 버전을 설치할 수 있습니다.
기존 라이선스 정보는 유지됩니다. 사용 중인 프로그램이 자동으로 교체되지는 않습니다.

버전별 설치파일과 변경 내용은 [Releases](https://github.com/mibooclouddata-boop/shi-drawing-releases/releases)에 보관합니다.
`latest.json`은 최신 버전의 다운로드 주소, 크기와 SHA-256을 제공합니다.
별도 Windows 코드 서명 인증서는 사용하지 않습니다.
